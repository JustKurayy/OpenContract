# OpenContract
I've been playing Hitman: Blood Money for a while & love the game, but the lack of moddabiltiy kinda hurts me and I wished there was a way to add more levels or items etc. So I vibecoded this since I'm not a game engine dev. This project has been made by GPT5.6 Sol (High) over several hours of development. This project is just a fun test. Not affiliated with anything, just a standalone project to see how far agentic agents can reverse engineer old games to "remaster" them & make them moddable.

### What does this project contain?
OpenContract uses bgfx (https://github.com/bkaradzic/bgfx) DirectX11 as the main renderer. The original renderer has not been reversed engineered, nor will I ask GPT5.6 to do that since I wanted a modern renderer. For future updates I'll switch over to DirectX12 for better rendering. Currently the engine boots into several missions, has a basic renderer and re-uses the old animation system (reversed engineer by GPT5.6)

### Which levels are playable
Here's a list of missions that are currently bootable. 
- M00 (Death of a Showman)
- M04 (Flatline)
- M08 (Death on the Mississipi)
- M09 (Till Death do us part)
- M12 (Amendment XXV)
- M13 (Requiem)
